# Smart Emergency Response Dashboard

A web-based dashboard for managing and monitoring reported accidents and emergency response activities.

## Features

- Accident reporting
- Add new accident details
- Edit accident information
- Delete accident records
- Search accidents
- Filter accidents by severity
- Sort accidents by severity
- Track critical accidents
- Track resolved accidents
- Monitor response teams
- Interactive and responsive dashboard interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
